# App Tracker — сборка APK через GitHub Actions

## Как запустить сборку без установки чего-либо на компьютер

1. Зайди на github.com, создай новый **пустой** репозиторий (без README, без .gitignore — они уже есть здесь).
2. Открой созданный репозиторий → "Add file" → "Upload files".
3. Перетащи в окно браузера ВСЕ файлы и папки из этого архива, сохраняя структуру (папки .github, app, и файлы settings.gradle.kts, build.gradle.kts, .gitignore).
4. Нажми "Commit changes" (в поле branch укажи `main`).
5. Перейди во вкладку "Actions" репозитория — там должна запуститься сборка "Build debug APK". Подожди 2-4 минуты.
6. Когда сборка завершится зелёной галочкой, зайди внутрь неё и в самом низу найди раздел "Artifacts" → скачай `app-debug`.
7. Это будет zip с файлом `app-debug.apk` внутри — перекинь его на телефон (например, через тот же Telegram "Избранное"), открой и установи (Android спросит разрешение "Установить из неизвестных источников" — это нормально для отладочной сборки).

## Что делает эта версия

Пока приложение умеет только одно: появляться в списке "Поделиться" и показывать всплывающее сообщение с package id из полученной ссылки Play Market. База данных, список, экран редактирования — следующие шаги.

## Если сборка упадёт с ошибкой

Открой вкладку Actions → упавший запуск → разверни шаг, где красный крестик, и посмотри текст ошибки в логе. Можешь скопировать текст ошибки и разобраться вместе с Claude.
